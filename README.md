# NestRelay

Telegram bot that aggregates, deduplicates and classifies real-estate listings, offers masked chats, favorites, reporting and delivers filtered listing subscriptions via Telegram.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
